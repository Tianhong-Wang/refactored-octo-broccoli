# refactored-octo-broccoli

A simple Streamlit app ready for deployment on [Streamlit Community Cloud](https://streamlit.io/cloud).

## Deploy to Streamlit Community Cloud

1. Push this repository to GitHub (already done).
2. Go to [share.streamlit.io](https://share.streamlit.io) and sign in with your GitHub account.
3. Click **New app**, select this repository, set the branch to `main`, and set the main file path to `streamlit_app.py`.
4. Click **Deploy** — your app will be live in seconds!

## Run locally

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```
